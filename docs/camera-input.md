# 相机视角、裁切与模型输入

新建训练使用 `image_profile=insert-roi160-v1`。参数来自实际两路 1280×720 相机画面，以及旧成功轨迹的开始、接近和完成帧人工选取。

| 视角 | 原图裁切 `(x, y, width, height)` | 最终 RGB 图像 |
|---|---|---|
| wrist_1 | `(360, 0, 720, 720)` | 160×160 |
| side_policy | `(180, 280, 400, 400)` | 160×160 |
| side_classifier | 完整原图 | 128×128 |

坐标原点为左上角，右/下边界不包含；NumPy 分别为 `frame[0:720, 360:1080]` 与 `frame[280:680, 180:580]`。两 policy ROI 都是正方形，裁切后使用 `INTER_AREA` 缩小，避免把整张 16:9 画面拉成正方形。腕部保留完整高度，以覆盖插座在接近时的上下移动；侧面保留夹爪、插头、插座和运动余量。

`side_classifier` 继续使用原有完整视野、128×128 和 `INTER_LINEAR`，像素变换与已训练 classifier 一致。它与 side_policy 共用一次物理相机读取，但有独立的模型输入变换。

## 网络、数据与版本

`hilserl/image_profile.py` 是实时输入与示范重建共用的变换定义。新 profile 拒绝非 1280×720 原帧，禁止把已缩小的 128 图当原帧上采样。录制仍保存完整连续视频，原始步骤另存 profile 名称；SERL 导出携带该版本。

旧 ResNet 实现内部默认把图片再缩到 128×128。新 SAC factory 显式传入 `encoder_image_size=(160,160)`，因此 CNN 实际输入为 160，ResNet 输出空间特征从 4×4 变为 5×5。卷积与归一化预训练权重保持加载；任务空间池化参数由新版单独初始化。

新 seed `demos/fixed_xyz_roi160_v1_20260914` 从旧 13 条/1,004 步的原始连续录像帧重建，按 capture_id、时间戳、segment 和局部帧号精确匹配。只替换两 policy 图像；state、动作、reward、done、mask、步骤 ID 和 classifier 图像逐字节保留。录像是 H264 有损编码，重建像素来自解码原分辨率录像，不声称等于采集前未压缩像素。源录像、索引、映射和派生文件均有 hash。

配置固定新 seed manifest 的 SHA-256；loader 校验 profile 完整参数、图像形状和文件内容。online 与 demo 必须匹配同一 profile。未来从新版原始录制直接构建示范时，builder 读取其不可变配置和原始步骤 profile，并保留已采集的对应尺寸图像。

旧 run 配置缺少 image_profile 时，明确继续 `full-frame128-v1`。续训和评估读取所选 run 的原配置；不能把旧模型或旧 seed 混入不同输入版本的新 run。改变 ROI 也需要新的 profile 名称、seed 与新 run，不可修改同名 profile 后继续旧 checkpoint。

同一 ROI 已有 128、160、192、224 四个明确版本，使用 `insert-roi<size>-v1`。当前选择160作为细节与开销的工程起点，不声称已证明其真机成功率最佳。不同大小或视野的完整 checkpoint 不能隐式混用。

## 后续移到正面

正面相机仍需让夹爪与插头不挡住插孔、对准间隙和接触过程；略带俯视或斜角是否更适合，要以移动后的实际画面确认。此处裁切只为当前侧视机位校准。移动后创建独立前视 profile，重选 ROI 并采集前视示范；已有侧视图像不能直接充当前视训练样本。成功分类器也有视角依赖，需用前视成功/失败样本重新核验或训练。人工最终 0/1 标签的所有权不变。

## 内存与使用

新默认 batch size 为 128，人工示范与 online 各 64，`cta_ratio=2`、学习率等保持原配置。224 输入下的 batch 256 在目标 GPU 的 0.75 显存限制与保守预取验收中出现显存不足，因此不会直接沿用原 batch 256。

目标主机约 31 GiB RAM。两路 policy 提高分辨率后，原来每池 200,000 的上限可能超过可用内存，因此新默认将 online 和 demo 的 `replay_buffer_capacity` 各设为 20,000 存储槽位；图像数组满容量约 9.38 GiB，两池的图像支撑槽位也计入上限。缓存是环形内存，磁盘原始录制和保存的回放块继续完整保留；每个新 run 的总采集步数不因此减少。旧 run 缺少该配置仍沿用原容量。

控制台刷新后选择新建训练使用新 profile。采集与运行时通过同一输入处理；“续训 Learner”继续原模型的输入版本。相机位置、镜头设置或插座位置明显改变时，应重新检查 ROI 覆盖，避免沿用不再适合的裁切。

软件检查及原生 GPU 更新验证只证明输入契约可执行；策略成功率与学习速度需要新版真机记录和独立评估确认。
