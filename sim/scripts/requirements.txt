# sim/scripts/requirements.txt — pinned deps for A11/A12 schema smoke tests
#
# 作用范围: sim/scripts/ 下的 3 个 smoke-only 工具 (gen_mock_real_pkl.py,
# test_domain_alignment.py, test_mixed_training.py) + 它们的 pytest 套件
# (sim/scripts/tests/test_*.py)。
#
# Codex REVIEW-final #1 (HIGH env) — 背景:
#   - 默认环境为 numpy 2.2.6 + scikit-learn 1.5.1, 触发 ABI 不匹配
#     ("ValueError: numpy.dtype size changed, may indicate binary
#      incompatibility. Expected 96 from C header, got 88 from PyObject")
#   - sklearn 1.5.x 编译时绑定 numpy 1.x ABI; 运行时 import sklearn 即
#     segfault / dtype size mismatch
#   - 解决: 锁住一个 sklearn/numpy/scipy 互相兼容的组合
#
# Pin 选型理由:
#   - numpy 1.26.4 是 numpy 1.x 的最后一个稳定版 (1.26.4 兼容 Python 3.9-3.12,
#     包含后续 numpy 2.0 删掉的 np.float_ / np.int_ aliases, 平滑迁移)
#   - scikit-learn 1.3.0 是 sklearn 1.3 系列的稳定版, 编译时绑 numpy 1.x
#     ABI, 与 numpy 1.26.4 同代
#   - scipy 1.11.x 是 sklearn 1.3.0 的测试矩阵指定版本
#
# 不影响:
#   - sim/data/* (A2-A9): 只 import numpy, 不依赖 sklearn; ABI 无所谓
#   - real-side hilserl-fr3 experiments/: 用户/主线 agent 自管 env
#   - IsaacLab runtime: 独立 conda env, 不消费本文件
#
# Runtime verify: 已记录到 PROGRESS.md (A12 段), 实际跑通需 mainline agent 的
#   conda env 用本文件 install 后 `python -m pytest sim/scripts/tests/test_mixed_training.py -v`。
#   本会话内 base env (numpy 2.2.6 + sklearn 1.5.1) ABI 不匹配无法跑通, runtime
#   verify 标记 DEFERRED。

numpy==1.26.4
scipy==1.11.4
scikit-learn==1.3.0
joblib==1.3.2
threadpoolctl==3.2.0
